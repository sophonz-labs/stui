**`stui upgrade`** replaces stui with the latest release, the way `install.sh` put it there: it reads which release is latest, downloads the archive for this machine, checks it against that release's SHA-256 and swaps the binary in one rename. It then prints the new release's notes.

```sh
stui upgrade                    # to the latest release
stui upgrade --check            # only say whether there is one
stui upgrade --version v0.2.0   # this release, older ones too
```

The server stui leaves running in the background is still the old binary after the swap, so `stui upgrade` restarts it on the new one. tmux, its sessions and the agents in them are not touched.

A stui installed by Homebrew is left to `brew upgrade`, and when stui cannot write to its own directory it prints the install line that can.
