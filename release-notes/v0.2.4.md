**The logo is the sophonz wordmark.** The header now draws the same wordmark `st` prints when it starts, nine rows high, with the version on its last row. A terminal narrower than the wordmark shows the word `stui` instead.

**Config, plugins, upgrade and the clipboard now come from tmui.** stui uses tmui's packages for these instead of its own copies, so a fix in one reaches both. Nothing changes in how you use them: the config keys, `stui config show`, `stui ext` and `stui upgrade` work as before.
