**A state the program reported is marked.** When a program in a pane tells stui what it is doing itself (OSC 7501), the agents view says so: `working (reported)`, `asking (reported)`. A state read from hooks or the screen has no mark. The report ends when the program sends `state=clear` or the pane runs another program, and stui reads the screen again at once.

Claude Code does not report this way inside tmux: it asks the terminal first, and tmux neither passes the question on nor answers it, so Claude Code decides the terminal cannot take it. stui keeps reading Claude Code from its hooks and screen, as before.
