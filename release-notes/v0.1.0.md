First release.

- `stui`: a terminal UI for tmux sessions, windows and panes, and the coding agents in them, each idle, working (teal) or asking (orange).
- GitHub Actions per pane: the latest run of each workflow on the checked-out branch, through `gh`, with `o` opening the run in the browser.
- Attaching opens a full-size popup inside tmux 3.2+, so `prefix d` comes back to stui.
- Orchestration: `stui orch` and `stui worker` let one agent start, brief, wait for and merge the work of others, with worktrees, owned paths, ordered tasks and decision gates.
- `stui hooks install` for Claude Code, Codex, opencode, Pi, Gemini CLI, Kimi Code and Qwen Code; `stui usage` for their plan limits.
- Everything runs on this machine; the only network calls are `gh`'s.
