**`stui --workspace`: your session inside stui.** Attach to a session from the list, and stui no longer hands the whole terminal to tmux. It keeps:
- a sidebar on the left, with this machine, its sessions and windows, an icon for each agent, and the orchestration tree (a coordinator with its workers under it);
- the session in the middle, a real tmux client;
- an optional panel on the right, with the run's agent cards, its history and its documents.

Everything works with the mouse: click a window to switch, drag the borders, right-click for split, zoom and rename. A menu bar sits along the top. The prefix is `ctrl-]` (`ctrl-] ?` lists the keys), and `STUI_PREFIX` changes it. `ui: { workspace: true }` in the config makes it the default.

**Agent icons in the lists.** Sessions, windows, panes, agents and the orchestration tree show each agent's icon: a picture in Ghostty, kitty and WezTerm, and a coloured letter elsewhere (`STUI_ICONS=letters` forces the letter).

**`6` is Top.** CPU, load, memory and swap, sampled every 5 seconds, with how much of it is stui, the tmux server and its panes.

**`7` is Docs, and `stui doc` keeps a document.** Run `stui doc <file>` in a pane, and stui keeps a copy under `~/.stui/vault/<session>/<window>/`. `stui doc ls`, `stui doc cat` and `stui doc rm` manage them, the Docs view reads them rendered, and the workspace's Docs tab shows the same tree. Everything stays on this machine.

**The number keys are now 1 sessions, 2 agents, 3 orch, 4 CI, 5 usage, 6 top, 7 docs.**

Not checked in this release: the workspace in terminals other than Ghostty and tmux, and Linux by hand.
